# Phase 1 — St. Mary's SEO Command Centre

## Objective
Create one reliable operating layer for St. Mary's organic search so every important query has one intended landing page, every movement is measured, and ChatGPT can turn GSC data into a short action queue.

## Baseline
- SEO baseline date: 2026-10-01
- Website: https://smis.edu.in/
- Latest settled GSC data should normally exclude the most recent 2–3 days when comparing periods.

## Canonical intent rules
1. One commercial intent should have one primary landing page.
2. Supporting articles may rank for related long-tail searches, but should internally link to the primary commercial page.
3. Do not create a new page when an existing page already satisfies the same intent.
4. If multiple URLs receive meaningful impressions for one commercial query, review for cannibalization before publishing more content.
5. Informational NEET/JEE resources should link toward the relevant programme page without turning every resource into a sales page.
6. Claims must be factually supportable. Strong presentation is encouraged; wording that materially changes the meaning of a rank/result is not.

## Measurement rule
Do not judge a page edit the next day. Track:
- 7-day rolling impressions
- clicks
- CTR
- average position
- chosen Google ranking URL
- cannibalization
- changes versus previous 7 days
- changes versus 2026-10-01 baseline

Use 14–28 days before making a large reversal unless a technical indexing problem appears.
